# أدوات السيو — arcadia-tour.com

سكربتات بايثون استُخدمت في جولات التحسين (سبتمبر–أكتوبر 2026). كلها تعتمد على REST API لووردبريس
بكلمة مرور تطبيق (Application Password) محفوظة في `~/.netrc` على جهازك:

```
machine arcadia-tour.com
login <اسم_المستخدم>
password <كلمة_مرور_التطبيق>
```

(تُنشأ من: المستخدمون → ملفك الشخصي → Application Passwords. لا تضع كلمة المرور في الملفات أو الشات.)

| الملف | الوظيفة |
|---|---|
| `crawl.py` ثم `linkcheck.py` ثم `analyze.py` | زحف كامل لكل روابط خرائط الموقع وفحص الروابط وتقرير السيو (يحتاج `all_urls.txt`) |
| `publish_article.py` | نشر مقال جديد من ملف HTML مع العنوان والوصف والكلمة المفتاحية والصورة البارزة والتصنيفات |
| `apply_inbound_links.py` | إضافة فقرة «اقرأ أيضاً» بروابط إلى مقالات محددة داخل مقالات/صفحات ذات صلة (دفعات ≤10) |
| `add_inline_images.py` | إدراج صور داخلية بنص بديل من مكتبة الوسائط (`media_all.json`) |
| `add_pillar_guides.py` | إضافة روابط إلى صندوق «أدلة جديدة» في الصفحات الأساسية (داخل بيانات Elementor والمحتوى) |
| `fix_redirect_links.py` / `fix_elementor_links.py` | تصحيح الروابط الداخلية المحوِّلة داخل المحتوى وبيانات Elementor |
| `close_comments.py` | إغلاق التعليقات والتنبيهات على المقالات (دفعات 10) |
| `bold_to_h2.py` | تحويل سطور «الخط العريض» المستقلة إلى عناوين H2 |
| `apply_meta.py` | تطبيق عناوين وأوصاف Yoast (والصورة البارزة اختيارياً) من ملف خطة JSON، مع نسخة احتياطية. بدون `--apply` يعرض فقط ما سيُرسل |

تشغيل على ويندوز:
- عرّف `PYTHONUTF8=1` قبل التشغيل (في PowerShell: `$env:PYTHONUTF8 = "1"`)، وإلا يفشل حفظ ملفات JSON العربية بترميز النظام.
- ملف كلمة المرور يكون `%USERPROFILE%\.netrc` أو `%USERPROFILE%\_netrc`.
- للزحف: أنشئ `all_urls.txt` من خرائط الموقع، ثم `crawl.py` ← `linkcheck.py` ← `analyze.py` من المجلد نفسه. Cloudflare يخزّن HTML لساعات؛ للحصول على الحالة الفعلية أضف `?cb=<أي قيمة>` إلى كل رابط في `all_urls.txt`.

ملاحظات مهمة:
- أي تعديل على صفحة Elementor يجب أن يكون داخل `_elementor_data` لا في المحتوى فقط، ثم Elementor → Tools → Regenerate CSS & Data.
- خذ نسخة احتياطية قبل كل تعديل (السكربتات تحفظها في `deliverables/backups/`).
- بيئة التنفيذ ترفض الدفعات الكبيرة؛ اعمل بدفعات ≤10 عناصر.
