## لماذا ما قدرت أدخل لوحة WordPress؟

لوحة التحكم (`/wp-admin`) محمية بتسجيل دخول. في بيئة العمل الحالية:

- ما في يوزر أو باسورد محفوظين للموقع
- ما في Application Password لـ WordPress REST API
- أقدر أشوف صفحة تسجيل الدخول، لكن بدون بيانات الدخول ما أقدر أعدّل Yoast، الصفحات، الإضافات، أو Search Console من الداخل

**عشان أشتغل من داخل اللوحة، أرسل واحد من التالي (يفضّل مؤقت):**
1. يوزر + باسورد WordPress (أو حساب محرر)
2. أو Application Password من: المستخدمون → ملفك → Application Passwords
3. أو دعوة حساب جديد بصلاحية Administrator / Editor

بدون ذلك أقدر أكمل الفحص والتحسينات عبر الملفات/المحتوى المقترح، وأنت تنفّذ التعديلات من اللوحة — أو أعطيك خطوات دقيقة نسخ/لصق.

**الخلاصة:** الأساس التقني صار أفضل من يونيو 2026. العائق الأكبر ليس «وجود أوكرانيا» (هذا أصل استراتيجي للشركة)، بل **خلط مسار الحجز الحالي** مع إرث أوكرانيا + عقارات/علاج تفصيلي داخل نفس الواجهة والقوائم، مع كثرة URLs المتنافسة على نفس الكلمات للوجهات النشطة.

> **تحديث قرار أوكرانيا (من الإدارة):** الشركة من أوائل الشركات السياحية والتجارية العربية في أوكرانيا؛ الخدمة متوقفة مؤقتاً بسبب الحرب وستعود بقوة. لذلك **لا حذف ولا noindex جماعي** لمحتوى أوكرانيا السياحي/التجاري. التفاصيل في: `seo-ukraine-preserve-strategy-ar.md`

## 2) الجرد التقني

### Sitemap
- `https://arcadia-tour.com/sitemap_index.xml` → يعمل (بعد تحويل لـ `/?sitemap=1`)
- **297 صفحة + 224 مقال + 20 تصنيف ≈ 541 مدخل** (منها ~521 محتوى)
- مولّد بواسطة **Yoast SEO**

### robots.txt
- Cloudflare Content-Signals موجودة (طبيعي)
- Yoast block موجود
- **مشكلة:** السطر:
  ```
  Sitemap: https://arcadia-tour.com/?sitemap=1
  ```
  الأفضل والأوضح لـ Google:
  ```
  Sitemap: https://arcadia-tour.com/sitemap_index.xml
  ```

### تقنية مكتشفة من الواجهة
- WordPress + **Elementor**
- **Yoast SEO**
- **LiteSpeed Cache** + **Cloudflare**
- **Google Site Kit**
- بقايا إشارة لـ **Rank Math** (تحقق من اللوحة: عطّلها/احذفها إن كانت ما زالت مثبتة)

## 3) أكبر مشاكل SEO (مرتبة بالأولوية)

### 🔴 P0 — فصل مسارين بدل محو أوكرانيا

من خريطة الموقع تقريباً:

| نوع محتوى | تقدير الحجم | القرار |
|-----------|-------------|--------|
| سياحة/تجارة أوكرانيا (إرث الشركة) | جزء كبير من ~120 | **تبقى مفهرسة** — Hub + رسالة «متوقف مؤقتاً» |
| عقارات للبيع (كييف/أوديسا/كاربات) | ~29 | `noindex` أو أرشفة — ليست خدمة العلامة السياحية |
| علاج أمراض تفصيلي (إن لم يعد نشطاً) | ~10 | `noindex` أو دمج تحت مقال علاجي واحد |
| `old-post-*` | 3 | `noindex` أو حذف |
| إنجليزي `/en/` | ~263 | ربط hreflang؛ لا مساس بهوية أوكرانيا |

**المشكلة الحقيقية:** الرئيسية ومسار الحجز يخلطان «احجز كازاخستان الآن» مع إرث أوكرانيا/عقارات، فيضعف وضوح النية.

**الحل المعتمد (يحفظ ريادة أوكرانيا):**
1. **مسار A نشط:** كازاخستان، روسيا، بولندا، أوزبكستان، الصين — هيرو، قوائم، CTAs، محتوى جديد
2. **مسار B محفوظ:** أوكرانيا السياحية/التجارية مفهرسة تحت Hub قوي + بانر «خدمات متوقفة مؤقتاً — سنعود بقوة»
3. أوكرانيا تخرج من هيرو الحجز السريع؛ تبقى في «من نحن» + رابط ثانوي في الوجهات
4. `noindex` فقط للعقارات والعلاج التفصيلي الضعيف — **ليس** لصفحات السياحة/التجارة الأوكرانية
5. خطة عودة جاهزة: إزالة البانر + إعادة القائمة الرئيسية فور تحسّن الأوضاع

التفاصيل التنفيذية: **`seo-ukraine-preserve-strategy-ar.md`**

### 🔴 P0 — Reviews Schema مشبوه

على الرئيسية يوجد:

```json
"aggregateRating": {
  "ratingValue": "5",
  "ratingCount": "7546"
}
```

هذا رقم ضخم ودرجة مثالية. Google يعاقب المراجعات المزيفة/غير القابلة للتحقق، وقد يخفي الـ rich results أو يؤثر سلباً على الثقة.

**الحل:**
- احذف AggregateRating من Schema اليدوي إن لم تكن المراجعات من مصدر موثق (Google Business / Trustpilot / صفحة تقييمات حقيقية)
- أو اربطه بعدد تقييمات Google Business الحقيقي فقط

### 🟡 P1 — لا يوجد hreflang

الصفحات العربية والإنجليزية مفهرسة معاً بدون:

```html
<link rel="alternate" hreflang="ar" href="..." />
<link rel="alternate" hreflang="en" href="..." />
<link rel="alternate" hreflang="x-default" href="https://arcadia-tour.com/" />
```

**النتيجة:** نسخ EN/AR تتنافس أو تُفهم خطأ.

**الحل:** تفعيل hreflang عبر إضافة اللغة (أو Yoast + نظام ترجمة واضح)، وربط كل صفحة عربية بنسختها الإنجليزية إن وُجدت.

### 🟡 P1 — صفحات متنافسة على نفس الكلمة

مثال كازاخستان — عدة صفحات تتنافس على نفس النية:

- `/السياحة-في-كازاخستان/`
- `/kazakhstan-tourism-overview/`
- مقالات متعددة: تكلفة، عائلات، شتاء، أفضل شركة…
- نسخ `/en/tourism-in-kazakhstan/` وغيرها

**الحل:** اختر **صفحة عمود (pillar)** واحدة لكل وجهة، والباقي مقالات داعمة بروابط داخلية واضحة (بدون تكرار Title/نية بحث واحدة).

مقترح الأعمدة:
| الوجهة | الصفحة الأساسية |
|--------|-----------------|
| كازاخستان | `/السياحة-في-كازاخستان/` |
| روسيا | `/السياحة-في-روسيا/` |
| بولندا | `/السياحة-في-بولندا/` |
| أوزبكستان | `/السياحة-في-أوزبكستان/` |
| الصين | `/china-main/` |

و اجعل `/kazakhstan-tourism-overview/` → 301 إلى الصفحة العربية الأساسية أو noindex إن كانت مكررة.

### 🟡 P1 — صفحات ضعيفة المحتوى

| الصفحة | مشكلة |
|--------|--------|
| `/search-programs/` | ~296 كلمة + Meta مليان إيموجي ونص واجهة؛ تبدو أداة بحث لا صفحة SEO |
| `/offers-bookings/` | Title ضعيف: «العروض والحجوزات - اركاديا السياحية» + إيموجي في H1 |
| `/destinations/` | تكرار العلامة في Title: «أركاديا السياحية - اركاديا السياحية» |
| مدونة | عدة صور `empty alt` |

**الحل:**
- `search-programs`: **noindex** (أداة داخلية)
- حسّن Titles لـ offers + destinations
- أزل الإيموجي من H1/Titles الظاهرة في نتائج البحث

### 🟡 P1 — H1 الرئيسية ضعيف ككلمة مفتاحية

الحالي: «بوابتك إلى سحر السفر»  
أقوى للـ SEO (مع الحفاظ على الجمال):

> رحلات سياحية إلى كازاخستان وروسيا وبولندا مع مرشد عربي

أو أبقي الحالي وأضف H2 أقوى يحتوي الكلمة المفتاحية الأساسية (موجود جزئياً).

### 🟢 P2 — سرعة وتجربة

- Cloudflare cache للرئيسية ممتاز (HIT، TTFB سريع)
- HTML ~230KB+ مع Elementor — راقب Core Web Vitals من Search Console / PageSpeed
- فعّل/راجع LiteSpeed: minify CSS/JS، lazyload صور، WebP
- صور OG الحالية 612×408 — مقبولة؛ الأفضل ~1200×630

### 🟢 P2 — روابط داخلية وCTA

- القوائم تشير لوجهات جيدة
- يوجد FAQ Schema مفيد
- تأكد أن كل دليل مدينة يربط لصفحة الحجز + واتساب بنفس الرقم
- لا تُظهر روابط «الاستيراد من الصين» في فوتر السياحة العامة إن كان الهدف SEO سياحي أولاً (أو ضعها في قسم B2B منفصل)

## 5) خطة تنفيذ للوصول لأعلى نتائج البحث

### أسبوع 1 — ترتيب المسارين + تنظيف محدود (أعلى عائد)
1. حدّث/أنشئ **Hub أوكرانيا** + بانر «متوقف مؤقتاً» (بدون noindex للسياحة/التجارة هناك)
2. في Yoast: **noindex** فقط لـ العقارات + علاج الأمراض التفصيلي + `old-post-*` + `search-programs`
3. أخرج أوكرانيا من هيرو الرئيسية؛ أبقِ رابطاً ثانوياً في الوجهات / من نحن
4. أصلح سطر Sitemap في robots إلى `/sitemap_index.xml`
5. أرسل Sitemap في Google Search Console
6. احذف/عطّل Rank Math إن كان موجوداً
7. أزل أو صحّح AggregateRating في Schema

### أسبوع 2 — تعزيز الصفحات الرابحة
1. حسّن H1 الرئيسية + محتوى فقرة أولى بالكلمة المفتاحية
2. حدّث Title لـ `/offers-bookings/` و `/destinations/`
3. ابنِ روابط داخلية: رئيسية → 5 وجهات → أدلة المدن → واتساب/حجز
4. أضف hreflang للصفحات المزدوجة المهمة فقط أولاً (الرئيسية + 5 وجهات)

### أسبوع 3–4 — محتوى يستهدف نية الحجز
انشر/حدّث مقالات تجيب على بحث حقيقي (عربي خليجي):
- تكلفة رحلة كازاخستان للعوائل 2026
- تأشيرة كازاخستان / روسيا للخليج
- أفضل وقت لزيارة ألماتي
- برنامج 7 أيام ألماتي مع مرشد عربي
- مقارنة: كازاخستان vs أوزبكستان للعوائل

كل مقال يربط لصفحة الوجهة + صفحة الحجز + واتساب.

### مستمر
- راقب Search Console: انطباعات، نقرات، صفحات مستبعدة، Core Web Vitals
- لا تنشر محتوى إنجليزي مترجم آلياً ضعيفاً يكرر العربي
- ابنِ Backlinks: أدلة سفر، شراكات B2B، Google Business، منشورات منصات عربية

## 8) ملاحظة عن التوقعات

الوصول لـ «الأول في Google» يعتمد على:
1. تنظيف الفهرسة والتركيز الموضوعي (هذا تحت سيطرتكم)
2. جودة/عمق المحتوى مقابل المنافسين
3. إشارات خارجية (خرائط Google، روابط، مراجعات حقيقية)
4. الوقت — النتائج تظهر تدريجياً بعد إصلاح الفهرسة والزحف

لا توجد إضافة سحرية. أكبر مكسب فوري لكم الآن: **إيقاف فهرسة المحتوى غير السياحي النشط** ثم تقوية صفحات الوجهات الخمس.
