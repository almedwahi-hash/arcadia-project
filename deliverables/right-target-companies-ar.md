## 1. ICP — Ideal Customer Profile (واضح)

### من يشتري (WHO BUYS)

| البند | التعريف |
|-------|---------|
| **النوع** | مشغّل جولات صادرة (outbound) / wholesaler يرسل **مجموعات إلى كازاخستان/ألماتي** ويحتاج **DMC محلي** |
| **الدور** | يبيع الباقة لعملائه → يشتري ground من أركاديا (net B2B / white-label) |
| **الحجم** | مجموعات **15+ pax** (جدول مغادرات أو طلب MICE/group desk) |
| **البريد** | مكتب مسمّى: `groups@` · `outbound@` · `planners@` · `b2b@` · `holidays@` · `tours@` · `sales@` **أو** جهة معروفة بالاسم (مثل John @ Planners) |
| **ملاءمة المنتج** | Central Asia **أو** Russia **أو** اهتمام Silk Road لأول مرة + حاجة **عربية / حلال** |

### أسواق مفضّلة (Prefer)

| السوق | لماذا RIGHT |
|-------|-------------|
| **GCC outbound** (UAE / KSA / Qatar / BH / KW / OM) | عميل عربي → مرشد عربي + حلال = قيمة أركاديا مباشرة |
| **SG / HK / MY / ID — مجموعات مسلمة / halal** | حجم مجموعات + طلب ground موثوق لخط Stans |
| **India — MICE / groups needing ground** | مجموعات 15–40 + desk `groups@` / `tours@` / MICE |
| **Turkey — مشترو Orta Asya** | مغادرات KZ/KG/UZ نشطة · قرب ثقافي |

### من ليس عميلاً (NOT)

| استبعد | السبب |
|--------|--------|
| **B2C adventure UK** (Exodus, HF Holidays, Jules Verne, Regent, Wild Frontiers…) | يشغّلون CA لسوقهم الإنجليزي؛ لديهم مورّدون؛ cold = 0 رد B2B |
| **Vietnam outbound mass** يبيع Stans للسوق المحلي | منتج جاهز لديهم؛ لا حاجة عربية/حلال؛ batch8 = 0 رد |
| **Philippines / Jordan / Morocco cold** | خارج ICP الحالي أو يحتاج relationship لا bulk |
| **FIT-only / OTA تذاكر** بدون desk مجموعات | لا حجم 15+ · هامش ضعيف |
| **DMC مقرها KZ/UZ** | منافس لا مشترٍ |

### اختبار ICP السريع (قبل أي بريد)

1. هل يرسلون مجموعات **إلى** ألماتي/KZ (وليس فقط يبيعون «مغامرة» لسوقهم)؟  
2. هل يوجد دليل **15+ pax** أو desk مجموعات؟  
3. هل البريد **مكتب** (ليس تخمين / ليس دعم تذاكر)؟  
4. هل المنتج CA أو RU أو Silk Road أول مرة + **عربي/حلال**؟  
→ إن فشل أي بند = **لا تُدرج**.
