## 🔴 مشاكل حرجة يجب إصلاحها فوراً

### 1. خريطة الموقع (Sitemap) — خطأ 500 ❌
```
https://arcadia-tour.com/sitemap_index.xml → خطأ 500
```
**التأثير:** Google لا يستطيع اكتشاف صفحاتك تلقائياً — **هذا أخطر مشكلة SEO**

**الحل:**
1. WordPress → **Yoast SEO** → **الإعدادات** → **ميزات الموقع** → أوقف XML Sitemap ثم فعّله
2. **LiteSpeed Cache** → Purge All
3. إذا استمر الخطأ: عطّل إضافة **Rank Math** (تتعارض مع Yoast)
4. راجع **أدوات → صحة الموقع** للأخطاء

### 2. رقم الواتساب القديم في كل الصفحات
```
77064007561 → يجب تغييره إلى +77051181845
```
**الحل:** تثبيت **Better Search Replace** واستبدال في `wp_posts` + `wp_postmeta`

### 3. إضافتان SEO متعارضتان
- **Yoast SEO** ✅ (الأساسية — نستخدمها)
- **Rank Math** ⚠️ (يجب تعطيلها لتجنب التعارض)

## 🟢 تحسينات متوسطة (أسبوع 2-4)

### 1. Google Search Console
- ربط الموقع عبر **Site Kit** (موجود في لوحة التحكم)
- إرسال Sitemap بعد إصلاح خطأ 500
- مراقبة الأخطاء والفهرسة

### 2. الروابط الداخلية (Internal Link Juicer — مثبت)
- ✅ يعمل في الخلفية (Build complete)
- يربط صفحات الوجهات ببعضها تلقائياً

### 3. سرعة الموقع (LiteSpeed Cache — مثبت)
- ✅ Browser Cache: ON
- ⚠️ Public Cache: OFF — يُفضّل تفعيله
- Purge All بعد أي تعديل

### 4. Schema Markup (Yoast — مفعّل)
- Organization ✅
- TravelAgency — يُضاف تلقائياً بعد إكمال الإعداد

### 5. صور SEO
- كل صورة: alt text بالعربية + اسم الوجهة
- مثال: `alt="جبال ألماتي كازاخستان - أركاديا السياحية"`
