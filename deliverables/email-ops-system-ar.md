### 1.3 ما أفعله عند وصول رد

```
رد وارد
    │
    ├─► استفسار عام / طلب rate sheet / «أرسلوا التفاصيل»
    │       → أرد بقالب + واتساب (§2.1–2.4) — مسودة أو إرسال حسب §1.2
    │
    ├─► اهتمام B2B / طلب اجتماع
    │       → أبلغك فوراً + أجهّز مسودة رد + اقتراح موعد
    │
    ├─► عقد / MOU / pricing negotiation
    │       → 🔔 إشعار فوري — لا أرسل شيئاً بدونك
    │
    ├─► bounce / mailer-daemon
    │       → 🔔 + تحديث جدول الحالة «❌ bounce»
    │
    └─► spam / Re main www / web design pitch
            → Spam — لا رد
```

| نوع الرسالة | القالب | إضافة إلزامية |
|-------------|--------|---------------|
| استفسار عميل (عربي) | playbook §2.1 | رابط `wa.me/77051181845` |
| استفسار عميل (EN) | playbook §2.2 | NAP موحّد |
| شكر / «استلمنا» | رد قصير + «سنعود خلال 24h» | — |
| طلب معلومات (وجهة، pax، تواريخ) | §2.1/2.2 — سؤال واحد واضح | توجيه للواتساب |
| تأكيد دليل / verify email | «تم التفعيل» + لا معلومات زائدة | — |

### 3.2 أبلغك فوراً (🔔 — لا إرسال بدونك)

| نوع | الإجراء |
|-----|---------|
| **عقد / MOU / legal** | إشعار + انتظار |
| **سعر كبير / group 40+ / exclusivity** | إشعار + مسودة للمراجعة |
| **شكوى / refund / delay** | إشعار عاجل — WhatsApp Business |
| **شراكة مهمة** (وكالة A، فندق 5*، airline) | إشعار + اقتراح اجتماع |
| **bounce** | تحديث جدول + «لا retry» |
| **Out of office** | جدولة متابعة بعد تاريخ العودة |

### 3.3 ممنوع بدون موافقة

- ❌ **Outreach جديد** لأي شركة غير موجودة في قائمة معتمدة  
- ❌ **Bulk / BCC** — بريد مخصّص لكل شركة  
- ❌ **أكثر من مرفق واحد** في البريد الأول  
- ❌ **إعادة إرسال** لعناوين bounce (Seera، altayyar، إلخ)

## 5. عندما الكمبيوتر مغلق

### 5.1 الحقيقة الصريحة

| ما يعمل | ما **لا** يعمل |
|---------|----------------|
| Zoho Mail على الجوال — push للوارد | **Cursor Agent لا يعمل** بدون جلسة مفتوحة على جهازك |
| n8n Cloud/self-hosted — cron 24/7 | المساعد **لا يقرأ inbox** تلقائياً أثناء إغلاق Cursor |
| ليلى — واتساب/تيليgram follow-up | **لا إرسال بريد** من المساعد بدون جلسة + موافقة |
| Telegram `/status` — Admin Commands | تقارير يومية **لا تُولَّد** وحدها |

**الخلاصة:** المساعد = **مدير BD عند الجلسة**، وليس خادماً يعمل 24/7 على جهازك المحلي.

### 5.2 حلول عملية (مرتبة بالأولوية)

| # | الحل | الوصف | الحالة |
|---|------|-------|--------|
| 1 | **Zoho Mobile** | push لـ `info@` — أنت ترى الوارد فوراً | ✅ فعّل الآن |
| 2 | **WhatsApp Business** | للعاجل: +77051181845 — ليلى تعمل عبر n8n | ✅ موجود |
| 3 | **n8n — تنبيه بريد جديد → Telegram** | workflow جديد: Zoho webhook/IMAP → Telegram Admin | 🟡 مرحلة 2 |
| 4 | **n8n Follow-up Cron** | `Arcadia - Follow-up Cron (3h-24h).json` — leads واتساب | ✅ للعملاء |
| 5 | **Admin Commands** | `Arcadia - Admin Commands.json` — `/status` | ✅ للـ leads |
| 6 | **Cursor Automations** | جلسة مجدولة (مثلاً يومياً 9:00) — إن متاح | 🟡 مرحلة 2–3 |
| 7 | **جلسة أسبوعية ثابتة** | 30 دقيقة Cursor + Zoho — أرشفة + KPI | ✅ موصى به الآن |

### 5.3 ما يجب تفعيله على جهازك

| الإعداد | لماذا |
|---------|-------|
| Zoho Mail app — إشعارات `info@` | لا تفوت رد B2B |
| WhatsApp Business — تنبيهات | عاجل + ليلى |
| Telegram — bot Admin | `/status` + تنبيهات مستقبلية |
| n8n — workflows مفعّلة | follow-up 3h/24h للعملاء |

### 5.4 workflow n8n مقترح — «بريد جديد → Telegram»

```
[Zoho Mail Trigger / IMAP Poll كل 5 د]
        │
        ▼
[Filter: مجلد Inbox أو 02-شراكات]
        │
        ▼
[IF: bounce → رسالة ⚠️ فورية]
[IF: subject contains شراكة/B2B/partnership → 🔔 رد محتمل]
[IF: from mailer-daemon → تحديث bounce log]
        │
        ▼
[Telegram Send → chat Admin]
```

**مرجع:** نفس نمط `Arcadia - Laila Telegram V5.json` (Telegram Send node) + `Arcadia - Admin Commands.json`.
