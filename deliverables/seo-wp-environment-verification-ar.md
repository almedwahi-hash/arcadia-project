## مراجعة ادعاءات الفحص السابق

| الادعاء السابق | الحكم بعد التحقق | الدليل |
|----------------|------------------|--------|
| Rank Math متعارض مع Yoast | **خطأ / إنذار كاذب** | Rank Math غير مثبت. ظهور `rank-math` في HTML = CSS توافق Astra للـ breadcrumbs فقط (`.rank-math-breadcrumb`) |
| لا يوجد hreflang | **خطأ** | Polylang يضيف `hreflang`: `ar` + `en` (+ `en-US` أحياناً) على الرئيسية والوجهات وأوكرانيا |
| Sitemap يعطي 500 | **قديم / غير صحيح الآن** | `sitemap_index.xml` يعمل 200 ويعطي XML من Yoast |
| واتساب القديم ما زال | **خطأ** | الرقم الظاهر `+77051181845`؛ القديم غير موجود في الرئيسية |
| أوكرانيا في قائمة الحجز الرئيسية وتحتاج إخراج | **غير دقيق** | قائمة الواجهة الحالية تركز على الوجهات النشطة؛ **أوكرانيا غير ظاهرة في nav الرئيسي المفحوص** |
| صفحة أوكرانيا بلا تنبيه توقف مؤقت | **خطأ** | يوجد تنبيه واضح أعلى الصفحة: الرحلات متوقفة مؤقتاً بسبب الظروف الحالية |
| Meta الرئيسية ضعيفة | **غير صحيح غالباً** | Title/Description محسّنة وواضحة |
| `?sitemap=1` في robots | **صحيح شكلياً** | موجود في robots عبر Yoast؛ لكنه **يعمل** ويُرجع الخريطة. تحسين الرابط لـ `/sitemap_index.xml` اختياري وليس عاجلاً |
| Schema TravelAgency + aggregateRating 7546 | **صحيح وجوده** | JSON-LD مخصص (ليس class يواست) يظهر في الواجهة مع `ratingCount: 7546` |
| هل 7546 «تقييمات مزيفة»؟ | **يحتاج تأكيد منكم** | الرقم يظهر أيضاً كشريط ثقة في محتوى الرئيسية («7546 عميل سعيد»). قد يكون رقم تسويقي داخلي مربوط بـ Schema. لا نلمسه حتى تؤكدوا مصدره |
| عقارات/search-programs/old-post مفهرسة | **صحيح من الواجهة** | `index, follow` حالياً على عيّنات مفحوصة |
| إضافات SEO كثيرة متعارضة | **مبالغ فيه** | Yoast هو الأساس + Snippets مخصصة لأركاديا |

## ما يبقى محتملاً للتحسين (بعد موافقتكم فقط)

هذه **مرشّحات** — ليست أخطاء مؤكدة يجب إصلاحها فوراً:

1. **مراجعة Schema التقييمات (7546)** معكم: هل الرقم معتمد من مصدر حقيقي؟

4. **مراجعة Search Console** عبر Site Kit (انطباعات، استبعاد، Core Web Vitals)  
5. **مراجعة Snippets** واحداً واحداً من اللوحة (لأن محرر الكود لم يُقرأ بالكامل آلياً بشكل موثوق في هذه الجولة)
