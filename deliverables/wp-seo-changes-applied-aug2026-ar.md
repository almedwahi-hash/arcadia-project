## الخطوات اليدوية المتبقية (5–10 دقائق)

1. WordPress → **Pages** → `ابحث عن رحلتك` (800)

2. نفس الشيء لـ `القسم العقاري` (604)
3. **LiteSpeed Cache → Purge All**
4. (اختياري) مراجعة Schema التقييمات 7546 في Code Snippets / Elementor
